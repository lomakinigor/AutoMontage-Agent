# Словарь

Слова, которые встретятся в курсе и в сообщениях агента. Instagram в курсе - запрещённая в России
соцсеть.

| Слово | Что значит |
|---|---|
| **Агент** | Claude Code или Codex, открытый в папке движка. Монтирует, проверяет и собирает ролики |
| **Движок** | AutoMontage-Agent - программа монтажа на вашем компьютере |
| **Папка движка** | Папка `AutoMontage-Agent` на вашем компьютере. Агента всегда открывайте в ней |
| **doctor** (проверка окружения) | Проверка, всё ли поставлено для монтажа. Пишет строки OK, WARN или FAIL и итог. WARN - предупреждение, это нормально: базовый монтаж работает. FAIL - чего-то важного нет, агент доставит сам ([урок 1](01-setup.md)) |
| **Ключ, файл .env** | Ключ - пароль для сервиса (Pexels, ElevenLabs). Хранится в локальном файле `.env`, в чат его не присылают |
| **Пульт роликов** | Окно со всеми вашими роликами: смотреть, оставлять правки, подтверждать черновую нарезку, утверждать |
| **Архив** | Вкладка пульта с карточками, убранными с глаз. Папки при этом не удаляются |
| **Проверка монтажа** | Отдельное окно для точной правки границ сцен и выбора B-roll. Открывается из карточки в пульте |
| **Карточка** | Одна тема в пульте. Оба её варианта лежат в одной карточке |
| **Вариант** | Instagram или YouTube - один текст с разными концовками. В пульте - вкладки над плеером |
| **Версия** | Очередная сборка ролика после правок. Прошлые версии лежат в «Истории» |
| **Паспорт ролика** | Служебный файл `project.json` в папке ролика. По нему пульт понимает, что это ролик |
| **Черновик** (draft) | Монтажный план, который ещё не утверждён. Каждая правка создаёт новый черновик |
| **Preview** | Полный ролик по черновику - то, что вы смотрите в пульте. Полный preview в 1080p собран уже в качестве финала: надпись «ЧЕРНОВИК» в углу рисует плеер пульта, в самом файле её нет. У фрагмента и 4K надпись вшита в кадр |
| **Черновая нарезка** | Ваша запись без графики, из которой агент вырезал паузы и повторы. Только для своей съёмки одной записью. Вы смотрите её в пульте, отмечаете оговорки правками на секунде и нажимаете «Нарезка готова». Это ещё не монтаж и не preview - только сокращённая речь |
| **«Нарезка готова»** | Кнопка подтверждения черновой нарезки, не путать с «Утверждаю». После неё агент собирает исходник и графику, а утверждаете вы потом готовый preview |
| **Исходник** (master) | Видео со спикером после вырезов: из него агент монтирует ролик, и вся графика привязана к его словам. У своей съёмки одной записью агент собирает его по подтверждённой нарезке, поэтому оговорку лучше вырезать до этого. Не путать с папкой «Исходники»: там лежат оригиналы записей |
| **Утверждение** | Кнопка «Утверждаю» или слово «утверждаю» в чате. Разрешение на финал ровно из этой версии |
| **Финал** | Итоговый файл, лежит в папке `final/`. После «Утверждаю» пульт за секунды копирует в него тот самый preview, который вы смотрели, и сверяет по SHA-256 - второй сборки нет. Фрагмент, 4K, устаревший preview или финал, который не удалось скопировать, агент собирает рендером |
| **Проверка финала** | Идёт в фоне после «Утверждаю»: движок заново расшифровывает готовый ролик (слова-паразиты, дубли, пропавшие слова, паузы) и проверяет обложку и надписи на кадрах. У роликов без съёмки и промо надписи не замеряются (⏭️) - их проверяете вы при просмотре preview. Только предупреждения: финал готов в любом случае. Состояние - строка под статусом карточки |
| **«Финал не нужен»** | Тихая кнопка в блоке «Действия» у утверждённой версии, у которой ещё нет финала. Карточка уходит в «Готов» с этой подписью, агент перестаёт ждать финал. Отменяется кнопкой «Вернуть: собрать финал» |
| **Чистка ролика** | Удаление промежуточных сборок после финала, чтобы освободить диск. Агент сам предлагает её, показывает гигабайты и список файлов и удаляет только после вашего «да». Финал, текущее ТЗ и исходники не трогает |
| **Рендер, сборка** | Превращение монтажного плана в готовый видеофайл. Занимает минуты, компьютер в это время лучше не усыплять |
| **Входящие** (inbox) | Список ваших правок, подтверждений нарезки и утверждений из пульта, который читает агент |
| **Хук** | Первые 3 секунды ролика: то, что удерживает зрителя |
| **CTA, кодовое слово** | Призыв в конце: «напиши „ВАЙБ“ в комментариях» или «подписывайтесь» |
| **Лид-магнит** | Подарок зрителю за кодовое слово: страница одним файлом, PDF и тексты для раздачи. Агент собирает, утверждаете вы в пульте |
| **Бренд-пак** | Ваш стиль для лид-магнитов: логотип, цвета, шрифты, соцсети и призыв по умолчанию. Лежит в личной папке, а не в репозитории движка |
| **UTM-метки** | Хвост ссылки вроде `?utm_source=youtube`. По нему в статистике сайта видно, что человек пришёл с этого лид-магнита |
| **Chatplace** | Сервис автоответов в соцсетях: присылает материал тому, кто написал кодовое слово. Агент его только проверяет |
| **Референс** (донор) | Чужой удачный ролик, по схеме которого делается ваш |
| **Карточка «Что делаем?»** | Стартовый выбор в начале работы: до четырёх вопросов - что делаем, формат, из чего собираем, как монтируем. Агент спрашивает только то, что неясно из задания |
| **Вертикаль 9:16 и горизонталь 16:9** | Формат кадра. 9:16 - как экран телефона: Reels, Shorts, Stories. 16:9 - как экран ноутбука: обычное видео на YouTube, пост. Рабочее качество движка - 1080p: 1080×1920 или 1920×1080 |
| **Ролик без съёмки** | Ролик без видео со спикером: анимация под тему, вашу озвучку или музыку. Ответ «без съёмки» в вопросе «Из чего собираем?» |
| **Маршрут** | Путь, по которому агент собирает ролик: что за ролик, формат, исходник и оформление. Выбирается один раз ответами в карточке «Что делаем?». «По референсу» - ответ про исходник, только для вертикали 9:16 |
| **Creative Motion** | Способ монтажа из вопроса «Как монтируем?»: новый дизайн под тему, анимации с нуля. «Решай сам» значит то же самое. Другие варианты - Creative Motion с оверлеями Higgsfield (тратит кредиты, только после сметы и вашего «да») и готовый стиль |
| **Оверлеи Higgsfield** | Вариант «Creative Motion + оверлеи Higgsfield»: тот же Creative Motion плюс AI-кинокадры поверх сцен или между ними. Тратит кредиты Higgsfield, только после сметы и вашего «да» |
| **Смета** | Расчёт до платной генерации: что генерируется, какой моделью, сколько вариантов, кредиты каждой партии и итог. Цены агент берёт у самого сервиса. Тратить можно только после вашего «да» на эту смету |
| **Слой анимаций** (motion-слой) | Отдельное видео со всей графикой, камерой и эффектами, которое агент собирает под ваш текст |
| **Motion-kit** | Готовые детали движка для слоя анимаций: камера, вставки, звуки, субтитры. Агент пишет только режиссуру и дизайн карточек, а движок заранее знает, что будет на каждом кадре, и проверяет это сам, а критик смотрит кадры ещё до рендера. Подробно - [инструкция motion-kit](../MOTION-KIT.md) |
| **Критик** | Отдельный агент, который только смотрит кадры до рендера и ставит каждой сцене оценки от 1 до 10 по пяти пунктам: мысль, расположение, движение, текст, ритм. Агент правит худшие сцены - до трёх кругов, видео рендерится один раз после этого |
| **Переход** | Способ сменить одну сцену другой: растворение, сдвиг, шторка, резкий толчок. По правилу движка - один заметный переход на ролик, на смене мысли. Есть в роликах без съёмки и промо; в ролике со спикером вместо переходов - наезд камеры |
| **Наезд камеры** | Камера плавно приближается к нужному элементу кадра - туда, куда должен смотреть зритель |
| **Счётчик** | Сцена с числом, которое прокручивается, как одометр, и встаёт на значении из текста ролика |
| **График** | Сцена со столбиками или линией: от 2 до 8 точек, значения и подписи - дословно из текста ролика |
| **Живой фон** | Лёгкое движение и блик фона сцены, на тёмном фоне - неподвижное зерно. Чтобы кадр не был плоским, а файл не раздувался |
| **Проверка движка** (гейт) | Автоматическая проверка ролика по одному правилу: ритм спикера, безопасная зона, голос и музыка и другие. У слоя анимаций - G1-G12 и G16, всего 13. У финала свои: обложка и надписи на кадрах (G13-G15) и повторная расшифровка (F1-F5) |
| **Отчёт проверок** | Итог проверок, который пересказывает агент: ✅ пройдено, ⚠️ предупреждение на вкус, ❌ стоп - объективная ошибка, ☑️ стоп снят исключением, ⏭️ не оценивалось |
| **«Preview не опубликован»** | Проверка нашла объективную ошибку, и движок не пустил новую версию в пульт. В пульте остаётся прошлая, агент исправляет и собирает заново |
| **Исключение из проверки** (waiver) | Записанное в плане ролика разрешение пропустить стоп одной проверки - с причиной. Бывает только у трёх: ритм спикера, спикер в первые секунды, чужое видео. Действует на всю проверку целиком, а не на одно место |
| **Живая камера** | Наезды, смены крупности, размытие, уход спикера под графику - чтобы кадр не стоял на месте |
| **План** | Отрезок, пока кадр спикера не меняется. У нас правило: не дольше 2-2,5 секунды |
| **Крупность плана** | Насколько близко спикер: во весь рост, по пояс, лицо крупно. Смена крупности оживляет кадр |
| **B-roll, сток** | Короткие вставки видео по смыслу фразы, например с Pexels |
| **Безопасная зона** (safe-зона) | Часть кадра, которую не закрывают кнопки и подписи Instagram. Текст должен быть внутри, это движок проверяет на каждом кадре |
| **Субтитры** | Слова речи на экране, привязанные к моменту произнесения |
| **Whisper** | Программа расшифровки речи, работает на вашем компьютере |
| **Remotion** | Инструмент, в котором агент рисует анимации кодом |
| **HeyGen** | Сервис аватаров: превращает текст или голос в видео с вашим цифровым двойником |
| **Digital Twin** (цифровой двойник) | Ваш аватар в HeyGen, снятый с вас на видео |
| **ElevenLabs** | Сервис синтеза голоса: читает текст вашим клонированным голосом |
| **Кредиты** (HeyGen) | Внутренняя валюта HeyGen. Около 32 кредитов на минуту аватара |
| **Higgsfield** | Сервис генерации картинок и видео нейросетями, в нём собраны разные модели, например Veo и Kling. Агент делает в нём кинокадры для AI-промо ([урок 10](10-ai-promo.md)) |
| **MCP** | «Розетка», через которую агент пользуется чужим сервисом от вашего имени. Higgsfield подключается так один раз, без ключа: вы входите в свой аккаунт |
| **Кредиты Higgsfield** | Внутренняя валюта Higgsfield из вашего тарифа. Картинка - около 2 кредитов, видео - от 7,5 до 24 и больше. Агент тратит их только после того, как вы утвердили бюджет |
| **AI-промо** | Рекламный ролик на 20-30 секунд без голоса: кинокадры от нейросети, надписи и музыка с ударами |
| **Ключевой кадр** | Картинка, с которой начинается план в AI-промо. Стоит дёшево, поэтому сначала выбирают ключевые кадры и только потом заказывают видео |
| **Image-to-video** | «Картинка в видео»: нейросеть берёт ключевой кадр как первый кадр клипа и дорисовывает движение |
| **Ролик без речи, саундтрек** | Ролик, где нет голоса: звук - один готовый саундтрек из музыки, ударов и свистов. Расшифровки и субтитров у такого ролика нет |
| **Provenance** (паспорт происхождения) | Запись рядом с файлом: откуда он взялся. У AI-кадра - сервис, модель, запрос, кредиты и SHA-256 файла |
| **Дубль** | Одна попытка записи. Агент собирает ролик из лучших кусков нескольких дублей. Дубли разными файлами идут без черновой нарезки: выбор дублей агент покажет вместе с preview |
| **дБ** (децибел) | Единица громкости. «Тише на 5 дБ» - заметно тише, «на 3 дБ» - чуть-чуть |
| **LUFS** | Средняя громкость всего ролика. Для соцсетей нормально около −14…−15 |
| **LU** | Разница громкости «на слух», как децибелы с поправкой на то, как слышит человек. Движок меряет в LU, насколько музыка под речью тише голоса: у цифрового двойника по утверждённому эталону около 38 LU |
| **Приглушение** (ducking) | Музыка сама становится тише, когда звучит голос, и громче в паузах |
| **Контакт-лист** | Картинка из кадров по всему ролику - быстрый способ увидеть его целиком |
| **SHA-256** | «Номер кузова» файла, как VIN у машины. Совпал номер - значит, это тот самый файл |
| **Пакет** | Несколько роликов, которые делаются за один заход |
