# AutoMontage-Agent v1.5.0 Batch-Reels Public Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Publish v1.5.0 with the proven single- and multi-Reel workflow while preventing client media and personal data from entering the public repository.

**Architecture:** Keep client delivery inside ignored projects/<id>/ workspaces and publish only generic orchestration rules over the existing CLI. Add an index-aware privacy gate beside Gitleaks, replace legacy real-speech fixtures with deterministic synthetic data, then validate the release from a clean clone.

**Tech Stack:** Node.js 20 CommonJS scripts and tests, React/Remotion, faster-whisper, FFmpeg/FFprobe, Git, Gitleaks and GitHub Actions.

**Spec:** docs/superpowers/specs/2026-09-06-v1.5.0-batch-reels-public-release-spec.md

## Global Constraints

- Version is 1.5.0; no automontage batch CLI is introduced.
- Never stage real media, transcripts, client filenames, private themes, music, local paths,
  logs or client QA reports.
- Use only the seven official lesson scenes; local motion explainers enter as muted broll.
- Keep final rendering behind the existing explicit approval gate.
- Do not force-push, bypass hooks or publish before explicit release approval.
- Work from current origin/main, not the detached v1.4.0 checkout.

- [ ] **Step 3: Implement stable policy constants and the exported checker**

~~~js
const FORBIDDEN_ROOTS = [
  'projects/', 'out/', 'tmp/', 'memory/', 'knowledge/',
];
const FORBIDDEN_FILES = new Set(['MEMORY.md', '_progress.md', '.env']);
const MEDIA_EXTENSIONS = new Set([
  '.mp4', '.mov', '.mkv', '.webm', '.mp3', '.wav', '.m4a',
  '.aac', '.flac', '.png', '.jpg', '.jpeg', '.webp', '.heic',
]);
const slash = '/';
const backslash = '\\';
const LOCAL_PATH_PATTERNS = [
  new RegExp([slash, 'Users', slash, '[^/\\s]+', slash].join(''), 'u'),
  new RegExp([slash, 'var', slash, 'folders', slash].join(''), 'u'),
  new RegExp([slash, 'home', slash, '[^/\\s]+', slash].join(''), 'u'),
  new RegExp(['[A-Za-z]:', backslash, 'Users', backslash, '[^\\\\\\s]+', backslash].join(''), 'u'),
];

function checkPublicPrivacy({root = process.cwd(), scope = 'tracked'} = {}) {
  const paths = listGitPaths(root, scope);
  const assets = parseAssetTable(readGitBlob(root, scope, 'ASSETS.md'));
  const issues = inspectPathsAndContents({root, scope, paths, assets});
  return {ok: issues.length === 0, issues};
}

module.exports = {checkPublicPrivacy};
~~~

Implementation rules:

- staged mode reads git show :<path>, never the unstaged working-tree version;
- tracked mode reads only git ls-files;
- symlink targets are scanned as text;
- .env.example is allowed and every other environment file is rejected;
- test payloads assemble forbidden strings from fragments so the checker does not flag itself;
- errors name the path and category but never print leaked content;
- binary media is allowed only when its path appears in the six-column ASSETS.md table.
