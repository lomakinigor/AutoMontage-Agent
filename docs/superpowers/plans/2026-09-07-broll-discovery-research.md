# B-roll Discovery Research Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to execute this research plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Найти и доказательно отобрать три наиболее надёжных GitHub-решения, которые помогут AutoMontage-Agent находить подходящие по смыслу изображения и видео B-roll в интернете.

**Architecture:** Исследование разделено на три независимых слоя: где брать легальный контент, как искать его по смыслу и как безопасно загружать результат в локальный проект. Кандидаты проходят сначала проверку репозитория и лицензий, затем одинаковый практический тест на реальных русскоязычных монтажных запросах; три победителя выбираются по общей шкале, а не только по числу звёзд.

**Tech Stack:** GitHub Web Search, GitHub CLI (`gh`), Node.js 20+, Python 3, `ffprobe`, существующий импорт B-roll AutoMontage-Agent.

**Spec:** `docs/superpowers/specs/2026-08-21-video-broll-media-import-design.md`

**Execution result (2026-09-07):** план выполнен в доступном без ключей объёме. Longlist,
фильтрация, scorecard, реальные загрузки и итоговый отчёт готовы. Полный TOP-5 blind test
Pexels честно оставлен незавершённым: официальный API требует ключ, а обход авторизации
запрещён. Реальный импорт проверен и выявил два существующих блокера AutoMontage.

## Global Constraints

- Исследование и тесты выполняются read-only относительно GitHub и внешних сервисов; установка в AutoMontage-Agent не входит в этот план.
- Не использовать платные API и не запрашивать API-ключи без отдельного явного решения пользователя.
- Не обходить авторизацию, paywall, robots.txt, DRM или ограничения лицензии источника.
- Финальный кандидат должен поддерживать изображения, видео либо быть сильным смысловым поисковым слоем для обоих типов контента.
- Для каждого найденного файла нужно уметь сохранить URL источника, автора, тип лицензии и дату получения.
- Проверять совместимость с локальным форматом AutoMontage: изображение или обычный видеофайл, который проходит `ffprobe` и может быть импортирован в `projects/<id>/assets/broll/`.
- Безопасный режим звука импортированного видео по умолчанию - `mute`.

### Task 4: Оценить shortlist по единой 100-балльной шкале

- Create during execution: `tmp/broll-research/scorecard.md`

**Interfaces:**
- Consumes: shortlist из Task 3.
- Produces: воспроизводимый рейтинг, где одинаковые качества сравниваются одинаково.

- [x] **Step 1: Применить веса**

  - 25 баллов - точность смыслового поиска и разнообразие результатов.
  - 20 баллов - прозрачная лицензия медиа и сохранение provenance.
  - 15 баллов - зрелость: реальные пользователи, contributors, releases, issues.
  - 15 баллов - активность: недавние изменения, рабочий CI, поддерживаемые зависимости.
  - 15 баллов - простота интеграции с Node.js/CLI и локальными папками проекта.
  - 10 баллов - изображения + видео, доступ к разрешению/длительности/формату.

- [x] **Step 2: Применить штрафы**

  Вычитать 30 баллов за неясное право скачивания, 20 - за необходимость browser cookies, 20 - за отсутствие provenance, 15 - за нестабильный undocumented endpoint, 10 - за обязательный платный API без рабочего бесплатного теста.

- [x] **Step 3: Не допустить ложный TOP-3**

  Победители должны закрывать разные части цепочки. Не выбирать три тонкие обёртки над одним и тем же stock API; минимум один кандидат должен быть сильным источником медиа, один - смысловым поиском/ранжированием, а третий - либо надёжным резервным источником, либо безопасным универсальным получателем.

- [x] **Step 1: Подготовить 10 запросов без персональных данных**

  Набор должен включать предмет, действие, абстрактную бизнес-идею, интерфейс приложения, российский контекст, человека без требования конкретной личности, вертикальное видео, горизонтальное видео, иллюстрацию и материал без людей.

- [ ] **Step 2: Получить TOP-5 результатов на каждый запрос - Pexels заблокирован без API key**

  Сохранить название, preview URL, source URL, автора, лицензию, тип медиа, размеры, длительность и причину, почему результат соответствует фразе.

- [ ] **Step 3: Проверить качество вслепую - переносится в acceptance test с Pexels key**

  Оценить первые пять результатов по шкале 0–2: `0` - не подходит, `1` - можно использовать после ручного выбора, `2` - подходит сразу. Итоговая смысловая точность - доля баллов от максимально возможных 100.

- [x] **Step 4: Скачать по одному разрешённому фото и видео**

  Проверить тип файла, размер, разрешение и длительность через `file` и `ffprobe`; убедиться, что рядом сохранены provenance и условия лицензии. Не скачивать материал, если правила источника этого не разрешают.

- [x] **Step 5: Проверить путь до AutoMontage без изменения движка**

  На временном test-проекте импортировать файлы существующей командой/интерфейсом Review Workbench. Убедиться, что изображение и видео нормализуются, видео по умолчанию получает `audioMode: mute`, а исходные URL и лицензия не теряются в исследовательском отчёте.
