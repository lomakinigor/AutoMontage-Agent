# ТОП-3 / 3. Автопроверка кадров финала – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Финальный QA сам находит три частые ошибки, которые сейчас ловит только глаз Дмитрия: пустой или чёрный кадр 0 (обложка в ленте), текст за краем кадра или обрезанный, наложение надписей друг на друга.

**Architecture:** Две чистые функции-гейта (`cover-frame-gate.js`, `text-layout-gates.js`) судят по числам и прямоугольникам. Замер кадра 0 – расширение существующего ffmpeg-замера в `scripts/layer/sheet.js`. Реальные прямоугольники текста берутся из DOM отрендеренных кадров (Chrome Remotion, `renderStill` + `getBoundingClientRect`) по уже существующим меткам `data-kit-text` / `data-motion-text` и новой метке `data-qa-text` на блоках урока. Обе проверки добавляются в `FINAL_CHECKS` раннера из плана ТОП-3 / 2 и попадают в тот же отчёт `qa/final-<stamp>`.

**Tech Stack:** Node.js 20 (CommonJS), `node:test`, `@remotion/bundler` и `@remotion/renderer` 4.0.504 (уже установлены), ffmpeg.

**Spec:** программа доработок, пункты 2 и 3 (память проекта `engine-upgrade-program`); исследование кода 2026-10-17: кадр 0 сейчас нигде не проверяется по содержимому (`motion-preview-gates.js:29,163-165` пропускает чёрное начало до 1 с намеренно), G5 проверяет только заявленную геометрию, наложения надписей не проверяет никто.

**Отклонение от плана:** G14 сделан предупреждением (`warn`), а не `fail`, как и все гейты финального QA, которые никогда не блокируют финал. Ниже по тексту плана G14 = `fail` оставлен как исторический замысел; причина отклонения – в шапке `scripts/qa/text-layout-gates.js`.

## Global Constraints

- Зависит от плана ТОП-3 / 2: использует `FINAL_CHECKS`, `runFinalQa`, `ctx` оттуда. Ветка `feat/top3-frame-qa` от ветки плана 2 (или от `main` после его мержа), отдельный worktree.
- Рендер кадров для замера – только на Mac; на сервере тесты с Chrome идут так же, как существующие `tests/layer-render-still.test.js` (с `skip`, если Chrome недоступен).
- Безопасная зона – только `safeRect(width, height)` из `scripts/qa/safe-rect.js`, без новых чисел.
- Пороги (константы): `COVER_EDGE_SHARE_MIN = 0.001` (тот же `SHARE_THRESHOLD`, что у G12 – импорт, не копия), `COVER_LUMA_MIN = 20` (средняя яркость 0–255), `OVERLAP_SHARE_MAX = 0.04` (доля площади меньшего прямоугольника), `TEXT_FRAMES_MAX = 40`, `FALLBACK_FRAMES = 16`, `MIN_OPACITY = 0.05`.
- Статусы: G13 и G15 – `warn`, G14 – `fail` (как существующий G5), но финальный QA не блокирует публикацию (правило плана 2).
- Новый селектор один на весь движок: `TEXT_SELECTOR = '[data-kit-text],[data-motion-text],[data-qa-text]'`.
- Документы по-русски, без U+2014. Push и PR – только по «да» Дмитрия.

## Review Focus

1. Ролик намеренно начинается с затемнения: кадр 0 чёрный – ожидается `warn` с подсказкой «обложка в ленте будет чёрной», а не молчание; тест в Task 1.
2. Подпись субтитров и её подложка – это части одного блока (`caption-3` и `caption-3b`), их пересечение не наложение; тест в Task 2 (одинаковый префикс до `b` не считается).
3. Невидимый блок (прозрачность 0 перед входом, `visibility: hidden`) лежит поверх другого – не наложение; сборщик отбрасывает элементы с `opacity < MIN_OPACITY`; тест в Task 3.
4. Шаблон без меток текста (старый проект) – G14 и G15 `skipped` с причиной «в кадрах нет размеченного текста», а не `pass`; тест в Task 2.
5. Chrome не запустился или бандл не собрался – проверка возвращает гейты G14/G15 `skipped` с текстом ошибки, остальной отчёт пишется; тест в Task 3.
