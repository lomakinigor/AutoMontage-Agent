# Higgsfield через MCP

Higgsfield – текущий провайдер AI-кадров. Он живёт в сессии агента как MCP-сервер, а не как
адаптер движка: движок видит только скачанные локальные файлы с SHA-256 и `provenance.json`.

## Подключение

```bash
claude mcp add --scope user --transport http higgsfield https://mcp.higgsfield.ai/mcp
claude mcp login higgsfield --no-browser
```

- Вход – OAuth в аккаунт пользователя. API-ключ не нужен и не запрашивается; ключи и токены
  в чат, логи, Issues и файлы проекта не попадают.
- `--no-browser` печатает ссылку входа: пользователь открывает её сам и подтверждает доступ.
- Генерация тратит кредиты тарифа пользователя. До любой платной задачи – `get_cost` и явное
  «да» на смету: партии или всего плана с разбивкой по партиям
  ([cost-and-consent.md](cost-and-consent.md)).
- Проверка: `claude mcp list` показывает `higgsfield` как connected; инструмент баланса
  отвечает числом кредитов.

### macOS и SSH

OAuth-токен Claude Code на macOS хранится в Keychain. В SSH-сессии связка ключей заблокирована,
поэтому `claude mcp login` и `claude -p` по SSH падают с ошибкой авторизации даже при рабочем
входе в графической сессии. Запускай генерацию там, где `claude -p` уже залогинен (терминал
в графической сессии того же Mac), или разблокируй связку ключей самим пользователем. Не
переноси токены между машинами и не сохраняй их в файлы.

## Интерактивный режим

В интерактивной сессии вызывай инструменты `mcp__higgsfield__*` напрямую: сначала стоимость,
затем генерация, затем ожидание результата по `job_id`. Имена инструментов смотри в списке
MCP текущей сессии: провайдер может их менять.

## Headless-партия

Для длинной партии удобно запустить отдельный процесс, который вернёт машиночитаемый итог:

```bash
claude -p "$(cat projects/<id>/assets/ai/batch-02.prompt.txt)" --allowedTools "mcp__higgsfield"
```

Промпт партии обязан содержать:

- точный список задач (сцена, вариант, модель, параметры, путь к локальному референсу);
- жёсткий потолок: «не трать больше N кредитов; если get_cost партии больше N – ничего не
  запускай и верни STOP»;
- запрет повторов: «при ошибке или отказе модерации не повторяй и не меняй промпт, верни ошибку»;
- формат ответа – только JSON-строки и итоговые строки баланса:

```text
{"scene":"s02","variant":"a","model":"veo3_1","job_id":"<id>","url":"<url>"}
{"scene":"s02","variant":"b","model":"kling3_0","job_id":"<id>","url":"<url>"}
CREDITS_SPENT=31.5
BALANCE=<остаток>
```

После ответа сверь `CREDITS_SPENT` с согласованным бюджетом. Расхождение – стоп и вопрос
пользователю, а не следующая партия.

## Скачивание результатов

URL результатов – временные CDN-ссылки, внутри есть id аккаунта. Сразу скачай файл в
`projects/<id>/assets/ai/` и дальше работай только с локальной копией:

```bash
curl -fsSL -o projects/<id>/assets/ai/s02-a-veo.mp4 "<url>"
shasum -a 256 projects/<id>/assets/ai/s02-a-veo.mp4   # Linux: sha256sum
ffprobe -v error -show_entries stream=codec_type,width,height,r_frame_rate,duration -of json projects/<id>/assets/ai/s02-a-veo.mp4
```

URL, job id и хэш запиши в `provenance.json` ([provenance.md](provenance.md)). Сам URL не
вставляй в brief, Issue, коммит или публичный отчёт.
