# Лицо автора из его собственной записи

Если в AI-кадрах должен быть сам автор, модель получает референсы только из его собственной
записи и только с его согласия.

## Согласие

- Спроси явно: «Можно сгенерировать кадры с вашим лицом по кадрам из вашей записи?»
- Чужие лица (коллеги, клиенты, знаменитости) не генерируй даже по просьбе без согласия
  этого человека; знаменитостей и публичных персон не генерируй вовсе.
- Запиши согласие в `provenance.json` (`consent`: кто, когда, на какие кадры).

## Как выбрать референсы

1. Возьми исходник, который автор сам дал для этого ролика (его запись с камеры).
2. Найди 3 резких кадра: глаза открыты, лицо анфас или в лёгком повороте, без смаза, без
   рук у лица, ровный свет.
3. Вырежи лицо с запасом (плечи и волосы в кадре), сохрани PNG в
   `projects/<id>/assets/ai/refs/`:

```bash
ffmpeg -ss 12.4 -i projects/<id>/input/<запись>.mp4 -frames:v 1 \
  -vf "crop=720:720:600:180" projects/<id>/assets/ai/refs/face-01.png
```

4. Посмотри каждый PNG глазами: закрытые глаза и смаз модель переносит в результат.

## Почему не папка фотографий

Случайные фото из общих папок дают чужое или усреднённое лицо: там другие люди, старые снимки,
фильтры, другой возраст и очки. Реальный случай: подборка из папки фотографий дала героя,
не похожего на автора, и кадры ушли в брак. Кадры из текущей записи автора совпадают с тем,
как он выглядит в остальном ролике.

## Хранение

Референсы лица – персональные данные. Они живут только в `projects/<id>/assets/ai/refs/`,
не попадают в Git, Issues и публичные отчёты; в `provenance.json` пишутся локальные пути.
