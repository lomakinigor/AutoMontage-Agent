# Происхождение AI-файлов

Сгенерированные кадры и клипы входят в ролик только как локальные файлы проекта с хэшем и
записью о происхождении. Файл – `projects/<id>/assets/ai/provenance.json`.

```json
{
  "version": 1,
  "items": [
    {
      "file": "assets/ai/s02-a-veo.mp4",
      "sha256": "<sha256 локального файла>",
      "provider": "higgsfield",
      "model": "veo3_1",
      "params": { "quality": "high", "durationSec": 6, "aspect": "9:16" },
      "jobId": "<job id>",
      "prompt": "<полный промпт>",
      "references": ["assets/ai/s02-key-a.png", "assets/ai/refs/face-01.png"],
      "credits": 24,
      "createdAt": "2026-01-01T12:00:00Z",
      "consent": { "person": "автор ролика", "scope": "кадры s02–s04", "givenAt": "2026-01-01" },
      "sourceUrl": "<CDN URL – только локально>"
    }
  ],
  "soundtrack": { "track": "<название и лицензия>", "segment": "<start–end>" }
}
```

Правила:

- `file` и `references` – пути относительно папки проекта, никаких абсолютных путей.
- `sha256` считается по скачанному файлу; после обрезки или перекодирования – новая запись.
- `credits` – фактический расход задачи из ответа провайдера; сумма сверяется со сметой.
- `consent` обязателен, если в кадре реальный человек; иначе `null`.
- CDN-ссылки результатов содержат id аккаунта. `sourceUrl` допустим только в этом локальном
  файле; в brief, Issues, коммиты, CHANGELOG и публичные отчёты не попадают ни URL, ни id
  аккаунта, ни job id.
- Папка `projects/` игнорируется Git; перед коммитом движка privacy-check всё равно проверяет,
  что клиентские файлы не попали в индекс.
