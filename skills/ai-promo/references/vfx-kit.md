# VFX-набор пакета

Эффекты лежат в `templates/motion-pack/src/fx.jsx`, сцены – в `scenes.jsx`. Всё детерминировано
(сид-рандом), без внешних ассетов, поэтому любой кадр рендерится одинаково.

| Эффект | Компонент | Где применять |
|---|---|---|
| Тряска камеры | `Shake` / `shakeAt(f, hits)` | Удары музыки, вход AI-кадра, нажатие кнопки |
| Вспышка | `Flash` | Каждая склейка на ударе вместо провала в чёрное |
| Ударная волна | `Shockwave` | Дроп, взрыв кнопки, финальный знак |
| Искры | `Sparks` | Сборка заголовка, вход кадров, шаги HUD |
| Угольки | `Embers` | Фон AI-кадров и финала |
| Кино-шторки и виньетка | `Letterbox` | Все сцены: единый «трейлерный» кадр |
| Анаморфный блик | `Flare` | Перед ударом заголовка |
| Хромированный текст | `Chrome` | Заголовок, слоган, знак. Размер ≤ 112 px при ширине 1080 |
| Трейлерные надписи | `Slam` | 1–3 слова поверх AI-кадра: врезка с увеличения, уход в расфокус |
| Голографический HUD | `Holo` | Интерфейс продукта: запрос, шаги |
| Энергетическая кнопка | `EnergyButton` | Кульминация действия: нажатие → взрыв → прогресс |
| 3D-телефон | `Phone` | Результат на экране телефона – только реальная запись или экран |
| Расфокусный переход | `BlurPass` | Спокойный вариант: сцены перекрываются, без вспышек |

## Правила

- `Chrome` пишет одной строкой (`nowrap`): при ширине 1080 размер ≤ 112 px, длинную фразу дели
  на две строки или две надписи `Slam`. Проверь самую длинную строку кадром `stills.cjs`.
- Склейки – перекрытием сцен или вспышкой на ударе, а не чёрным провалом: провал в чёрное
  читается как обрыв ролика и ловится `blackdetect`.
- Тряска и вспышка – только на настоящих ударах трека; постоянная тряска утомляет.
- Не больше одной надписи одновременно; текст только из согласованной копии.
- Горизонталь 16:9 (1920×1080): safe zone `SAFE_16x9` – поля 60 px сверху и снизу и 80 px по бокам;
  `ASPECT` в `tokens.js` пересчитывает размер и `SAFE`, сцены шаблона перекомпонуй под широкий кадр.
- Safe zone 9:16: важное – между ~260 и ~1500 px по вертикали, поля по бокам ≥ 80 px; низ
  кадра перекрывают подписи и кнопки площадок.
- Шрифты – только из движка (`FontStyle`: Onest, JetBrains Mono), не системные.

## Оригинальный стиль

- Не делай знаки, похожие на знаки реальных брендов: форма, цвет и шрифт должны быть своими.
- Никогда не воспроизводи логотипы, персонажей и фирменные заставки франшиз, студий и
  кинокомпаний, даже «в духе» – только собственный стиль: свет, материал, ритм, типографика.
- Реальные интерфейсы продукта пользователя – из его экранов; чужие интерфейсы не рисуй.
